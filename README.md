# 绝妖星乱舞 · 真假魔法范围模拟器

练习 FF14 副本「绝妖星乱舞」**真假魔法范围交叉**机制瞬时判断的纯静态 Web 应用

## 玩法

场地中央为 BOSS（凯夫卡），每轮出现两类魔法预兆：

- **冰魔法（蓝）**：四象限中的一对**对角扇形**（左上+右下 或 右上+左下）。
- **雷魔法（紫）**：斜 ±45° 把场地四等分后**隔一相间的两条带**。

BOSS 头顶（雷/紫环）与脚底（冰/蓝环）各有一个 30° 俯视旋转环，同环两球状态一致：

- **白球无符号 ＝ 真**：预兆区危险、非预兆区安全。
- **红球带「?」＝ 假**：反转 —— 预兆区安全、非预兆区危险。

冰、雷彼此独立。在限定时间内判断两者叠加后的**真实安全区**并点击。结算时绿色为安全区、红色为危险区，并标记你的落点。

## 难度

| 难度 | 反应时间 |
|---|---|
| 休闲 | 10s |
| 普通 | 5s |
| 零式 | 3s |
| 绝境 | 5s 起，每次成功 −10%（最低 0.5s），答对 0.8s 后自动下一题；答错或超时即结束并重置得分 |

得分与最佳成绩仅在**绝境**模式显示并记录（持久化于 localStorage）。

## 设置

- 难度（上表四档）
- 学习模式：直接显示每个环的真/假标签
- 辅助分隔线：显示象限十字与条带分隔线

## 本地运行

ES Modules 需经 http 提供（不能直接双击 `file://`）：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

或用 VS Code 的 Live Server 扩展打开 `index.html`。
